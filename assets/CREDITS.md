# 에셋 출처와 제작 이력

프로젝트 규약(기획서 §11.3)에 따라 크레딧 불요 에셋도 전수 기록한다.

아래 Kenney 자료의 CC0 표기는 해당 팩에 관한 기존 입수 기록이다. OpenAI 생성물, 사용자 제공 원화, 프로젝트 가공물까지 모두 CC0로 표시하는 문서가 아니다. 각 항목에서 원본과 가공 이력을 구분하며, 이 기록 자체가 별도의 라이선스를 부여하지 않는다.
